# 🌟 Slimefun4-Modern 🌟

> Модернизированный форк легендарного плагина Slimefun4 с акцентом на производительность, чистоту кода, поддержку современных версий Minecraft и мультиплатформенность.

---

## 🎯 Цели нашего проекта (Project Goals)

Основная цель **Slimefun4-Modern** — вдохнуть новую жизнь в кодовую базу Slimefun, избавиться от легаси-ограничений десятилетней давности и сделать разработку аддонов и самого плагина максимально удобной.

### 1. ⚡ Поддержка новейших версий Java и Minecraft
* **Java 21+ и JDK 25**: Код адаптирован под новые версии виртуальной машины Java. Устранены проблемы с инкапсуляцией и динамической загрузкой агентов в тестах.
* **Minecraft 1.21.4+ и 1.22.x**: Полная нативная поддержка актуальных версий API.

### 2. 🧩 Мультиплатформенная архитектура (Multiplatform)
Мы постепенно уходим от жесткой привязки к Bukkit API, чтобы Slimefun мог работать везде:
* **Spigot / Paper** (классический плагин)
* **Fabric** (нативный мод для клиента и сервера)
* **NeoForge** (мод для интеграции в сборки)

Для этого мы внедрили слой абстракции **Platform Abstraction Layer** (`SFPlayer`, `SFItemStack`, `SFBlock`, `SFWorld`). Ядро плагина будет полностью переведено на работу с этими абстракциями.

### 3. 🧹 Рефакторинг и читаемость кода (Clean Code)
* **Очистка легаси**: Избавление от устаревших зависимостей (таких как CS-CoreLib).
* **Модульность**: Разделение монолитного плагина на независимые подключаемые модули.
* **Удобство модификации**: Код пишется так, чтобы любой разработчик мог легко добавлять новые предметы, рецепты и механизмы без изменения ядра.

### 4. 🛡️ 100% Стабильность и авто-тесты
* Мы починили и настроили все тесты под JDK 25.
* **1788 автоматизированных тестов** проходят с результатом **BUILD SUCCESS** при каждой сборке, гарантируя отсутствие багов.

## 🛠️ Как это устроено сейчас

Мы уже выполнили первый этап рефакторинга:
1. Создали пакет `io.github.thebusybiscuit.slimefun4.api.platform` с абстракциями основных сущностей игры.
2. Реализовали Bukkit-мост в пакете `bukkit` на основе `PersistentDataContainer`.
3. Добавили поддержку новых констант версий Minecraft в `MinecraftVersion` и списков биомов в ресурсах.
4. Настроили сборку в `pom.xml` для работы с JDK 25 и обновленным ByteBuddy.

## 🚀 Быстрый старт (Разработка)

### Сборка и тестирование:
Для сборки проекта и запуска всех тестов выполните:
```bash
mvn clean test
```

### Структура Git-репозитория:
* **origin** — ваш личный репозиторий для разработки, форков и коммитов.
* **upstream** — ссылка на оригинальный репозиторий Slimefun4 для подтягивания официальных обновлений:
```bash
# Получить обновления от официального Slimefun
git fetch upstream
git merge upstream/master
```
